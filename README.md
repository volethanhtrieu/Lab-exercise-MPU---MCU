# Lab-exercise-MPU---MCU

This repository contains the laboratory exercises for the Microprocessor - Microcontroller (MPU-MCU) course.

## Folder Structure

Below is an overview of the repository's folder structure to help you easily navigate through the lab materials, source codes, and simulation files:

### 📁 `lab01/`
Contains materials and exercises for **Lab 1**.
- **`lab01/`**: This inner subfolder contains the STM32CubeIDE project directories for exercises 1 through 7 (`ex01` to `ex07_lab01`). It also includes the `Lab_01.pdf` instruction manual.
- **Proteus Projects**: Files like `ex10.pdsprj` and `Ex5.pdsprj` used for circuit simulation.
- **`Figure/`**: Contains images and figures used in the lab documentation.

### 📁 `lab02/`
Contains materials and exercises for **Lab 2**.
- **`ex01_lab02/` to `ex05_lab02/`**: STM32CubeIDE project directories for exercises 1 through 5.
- **`VXL_VDK_Lab_2_Timer.pdf`**: The instruction manual for Lab 2.

### 📁 Tools & Environment (Root Directory)
The root directory also includes several installation files and resources for setting up the development environment:
- **`SetupSTM32CubeMX-6.18_1`**: STM32CubeMX setup executable.
- **`stm32cubeide_2.2.0_...sh`**: STM32CubeIDE installer script for Linux.
- **`stm32zipfile/`**: Compressed installation files for the required STM32 development tools.
- **`jre/`**: Java Runtime Environment directory.

## How to Use
- Read the **`.pdf` manuals** located in each lab folder for exercise instructions.
- Open the **STM32CubeIDE** projects by selecting the respective `ex*` folders as your workspace or importing them into your IDE.
- Use **Proteus** to open the `.pdsprj` circuit simulation files provided in `lab01`.
